注册 Azure 应用（免费）

目的：拿到一串 应用程序(客户端) ID，粘到 GOLD ALERT 登录页。不会扣费。不要创建密码。

1. 打开注册页面

  1. 电脑浏览器打开：Azure 应用注册
  2. 用你的 微软账号登录（和 OneDrive 同一个）。
  3. 如果提示创建免费 Azure 订阅：可以创建。绑卡一般是验证，这个用法不扣费。
  4. 进入后点顶部或页面上的 新注册 / New registration。

2. 填写注册信息

  1. 名称：GOLD ALERT
  2. 受支持的帐户类型：选
    「任何组织目录中的帐户和个人 Microsoft 帐户」
    英文类似 Accounts in any organizational directory and personal Microsoft accounts。
    不要选「仅此目录」。否则 Outlook/Hotmail 登不进去。
  3. 重定向 URI：
    • 平台选 单页应用程序 (SPA) / Single-page application
    • URI 原样填：https://alertdata.pages.dev/
    • 末尾斜杠 / 要带上
  4. 点 注册 / Register。

3. 复制 Client ID

  1. 注册成功后会进入应用「概览」。
  2. 复制 应用程序(客户端) ID / Application (client) ID。
    是一串类似 xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx 的字符。
  3. 这就是网页登录框要填的。可以发给我帮你写进页面。

4. 打开 API 权限

  1. 左侧点 API 权限 / API permissions。
  2. 应已有 Microsoft Graph → User.Read（委派）。没有就添加。
  3. 点 添加权限 / Add a permission → Microsoft Graph → 委托的权限 / Delegated。
  4. 搜索 Files.ReadWrite，勾选，添加。
  5. 不要勾选 Files.ReadWrite.All（权限过大）。
  6. 个人账号一般不用点「代表管理员同意」。你第一次在 GOLD ALERT 登录时，微软会弹窗让你同意访问 OneDrive。

5. 确认身份验证

  1. 左侧 身份验证 / Authentication。
  2. 平台里应看到 SPA，URI 为 https://alertdata.pages.dev/。
  3. 若主屏幕快捷方式打不开登录，再添加一条同样的 SPA URI：https://alertdata.pages.dev（不带斜杠）。
  4. 「隐式授权」不要勾选 Access tokens / ID tokens（SPA + PKCE 不需要）。

不要点「证书和密码 / Certificates & secrets」去新建客户端密码。网页用公开 ID 即可，密码放进网站反而不安全。

6. 回到 GOLD ALERT

  1. 打开 https://alertdata.pages.dev/
  2. 粘贴 Client ID → 登录 Microsoft → 同意访问文件。
  3. 电脑 EA 已同步 OneDrive 后，点「设定」才会取现价并写入提醒。
