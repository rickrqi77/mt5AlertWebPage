用快捷指令把提醒推到 EA

iPhone 输入现价和间隔 → 生成 15 个价格 → 存进 OneDrive → 电脑同步 → MT5 EA 自动读取。

一、电脑（做一次）

  1. 安装并登录 OneDrive，和手机同一账号。
  2. 建立文件夹 OneDrive\gold-alert。
  3. 右键该文件夹 → 始终保留在此设备上。
  4. 以管理员或当前用户运行仓库里的 scripts/link-onedrive-alerts.bat，把这个文件夹连接到 MT5 的 Common\Files\gold-alert。
  5. 下载并编译 GoldPriceAlert.mq5（v1.06）。
  6. 挂 EA 时勾选 InpUseLocalFile = true。可以不填 Cloudflare。

二、iPhone 快捷指令（做一次）

快捷指令 App → 右上角 + → 按下面添加动作。现价由你输入（建议看 MT5 或网页上的整数价）。

  1. 提问：提示「当前金价」，输入种类「数字」，存到变量 现价。
  2. 从列表中选择：1 / 2 / 3 / 4 / 5 / 10，提示「间隔」，存到变量 间隔。
  3. 四舍五入：对「现价」取整，模式选「始终向下」，存到变量 基数。（例如 4195.8 → 4195）
  4. 文本：先放一行 # gold-alert，存到变量 内容。
  5. 重复 7 次：
    • 计算：8 - 重复索引，再计算 基数 - 该数 × 间隔
    • 文本：上一行内容 + 换行 + 这个价格
    • 把结果存回 内容
  6. 文本：内容 + 换行 + ! + 基数（中间价默认不触发）
  7. 再 重复 7 次：
    • 计算：基数 + 重复索引 × 间隔
    • 追加到 内容
  8. 存储文件：
    • 文件名 alerts.txt
    • 目的地选 OneDrive / gold-alert
    • 打开「覆盖已有文件」
  9. 可选：通知「已写入 15 个提醒」。

三、文件格式

# gold-alert
4160
4165
4170
4175
4180
4185
4190
!4195
4200
4205
4210
4215
4220
4225
4230

一行一个价格。! 开头表示关闭（不触发）。最多 15 个。EA 发现文件变化后会立刻换一组价格。

四、通知

不经过 Cloudflare 时，触发会在 电脑 MT5 弹窗。要手机收，可继续用 Telegram（EA 直发或网页那套），或开 MT5 官方推送。
