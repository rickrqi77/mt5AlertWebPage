网站 → OneDrive → EA

平时网页不刷新。只有点「设定」才从 OneDrive 读取 EA 写下的现价，生成 15 档提醒并写回 OneDrive。EA 不访问 Cloudflare。

你需要提供的（做一次）

一个免费的 Microsoft 应用 ID。步骤：

  1. 打开 Azure 应用注册（用你的微软账号登录）。
  2. 点「新注册」。
  3. 名称填 GOLD ALERT。
  4. 受支持的帐户类型选：任何组织目录中的帐户和个人 Microsoft 帐户。
  5. 重定向 URI 平台选 单页应用 (SPA)，URI 填：
    https://alertdata.pages.dev/
  6. 注册后复制 应用程序(客户端) ID，粘贴到网页登录框。
  7. 「API 权限」确认有 User.Read 和 Files.ReadWrite（委派）。没有就添加 Microsoft Graph 委派权限，并代表自己同意。
  8. 不要创建客户端密码。网页只用公开的 Client ID，密码不要放进网站。

把 Client ID 发给我也可以，我可以帮你写进页面默认值。

电脑（做一次）

  1. OneDrive 与手机同一账号，文件夹 OneDrive\gold-alert 设为始终保留在此设备上。
  2. 运行 scripts/link-onedrive-alerts.bat。
  3. 下载 GoldPriceAlert.mq5（v1.08），编译后挂上。
  4. 参数：InpUseLocalFile = true，Cloudflare 地址留空。

手机怎么用

  1. 打开 alertdata.pages.dev，填 Client ID，登录 Microsoft。
  2. 选间隔，点「设定」：这时才取现价、生成提醒、写入 OneDrive。
  3. 可改触发/关闭后点「保存设置」，也会写入 OneDrive。
  4. EA 读取电脑上已同步的 alerts.txt，不经过 Cloudflare。
